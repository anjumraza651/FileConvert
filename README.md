# FileConvert

 HEAD

A browser-based React + Vite file conversion app.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
npm run preview
```

For Vercel, import this repository and use:
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Included tools

- Word DOCX to PDF
- PowerPoint PPTX to PDF
- Excel XLSX/XLS/CSV to PDF
- PDF to Word DOCX
- PDF to PowerPoint PPTX
- PDF to Excel XLSX
- Word DOCX to PowerPoint PPTX
- JPG/PNG images to PDF
- Merge PDFs
- Split PDF into page files
- PDF pages to PNG images

## Limitations

Most Office/PDF conversions extract text and rebuild a basic output. They do not preserve exact original page layouts, fonts, images, tables, animations, or complex formatting. Scanned PDFs require OCR, which is not included. Processing happens in the browser.
